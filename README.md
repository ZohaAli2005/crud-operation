🔥 Firebase CRUD Operations
A modern and responsive CRUD (Create, Read, Update, Delete) web application built using HTML, CSS, JavaScript, and Firebase Realtime Database. This project demonstrates how to perform real-time database operations with a clean and user-friendly interface.

✨ Features
➕ Create new student records
📖 Read data from Firebase
✏️ Update existing records
🗑️ Delete student records
🔥 Firebase Realtime Database Integration
📱 Fully Responsive Design
🎨 Modern and Professional User Interface
⚡ Fast and Real-Time Data Management
